# CodeAlpha_CGPACalculator# CGPA Calculator

## Project Description
The CGPA Calculator is a C++ console-based application developed as part of the CodeAlpha C++ Programming Internship. It calculates semester GPA and overall CGPA based on course grade points and credit hours.

## Features
- Input the number of courses.
- Enter grades and credit hours.
- Calculate total credit hours.
- Calculate total grade points.
- Calculate semester GPA.
- Calculate overall CGPA using previous academic records.
- Display course grades and final results.

## Programming Language
- C++

## Concepts Used
- Variables and Data Types
- Arrays
- Loops
- Conditional Statements
- Mathematical Operations
- Input and Output

## How to Run
1. Download or clone this repository.
2. Open `CGPA_Calculator.cpp` in Code::Blocks or Dev-C++.
3. Compile the program.
4. Run the application.
5. Enter course information to calculate GPA and CGPA.
